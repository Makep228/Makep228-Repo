# Demo Launcher

Automatically opens a chosen app after a period of no touch or movement.

- Rootless (Dopamine) tweak for iOS 16-18
- Settings page with on/off switch, idle time, target app, test launch and Respring
- Default target: com.apple.ist.demoloop, default idle time: 30 seconds

Built with Theos on Tweaks.build.
